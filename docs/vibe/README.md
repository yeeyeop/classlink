# Vibe Coding 日志索引

课程介绍要求每组至少提交 5 条高质量 Vibe 日志，并建议每条包含：

- 本次目标（Goal）
- 使用提示词（Prompt Used）
- AI 生成结果（AI Output）
- 遇到的问题（Issue Encountered）
- 迭代修改（Iterative Changes）
- 小组理解（Team Understanding）

本项目最终保留 6 条日志，按真实开发顺序记录从需求复核、业务闭环、实时数据流、3D 数字孪生、DeepSeek Agent 到工程交付的完整过程。旧版与当前实现不一致的日志已合并或删除，不再保留“信箱”和“全体通知”等已经撤销的功能作为最终事实。

| 编号 | 日志主题 | 主要证据 |
| --- | --- | --- |
| 01 | 需求复核、演示入口清理与管理员鉴权 | 删除旧管理员演示路由、初始化脚本、管理员接口角色校验 |
| 02 | 全量可用性、预约规则与 JSON 持久化 | 脱敏可用性 API、统一规则、原子写入、单元测试 |
| 03 | SSE 实时刷新、账号管理与单学生通知 | `/api/realtime`、客户端自动刷新、学生通知闭环 |
| 04 | 3D 数字孪生恢复与后端状态联动 | 点击拾取、状态映射、选中状态保持、GLB 延迟加载 |
| 05 | 管理员专属 DeepSeek 教室 Agent | 工具调用、领域提示词、两阶段预约/取消确认 |
| 06 | 工程测试、性能降级与最终打包 | `npm run verify`、浏览器验收、文档与安全打包 |

> 日志不记录任何 API Key、密码明文或会话令牌。DeepSeek Key 只允许保存在本机 `.env.local`，发布 ZIP 必须排除该文件。
