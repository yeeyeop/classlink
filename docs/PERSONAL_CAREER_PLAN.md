# 个人职业规划

> 本文作为小组材料模板。每位成员可在对应角色后用真实姓名替换，并按自己的目标调整年份与证书计划。

## 短期目标（6 至 12 个月）

- 打牢计算机网络、操作系统、数据库和软件工程基础。
- 完成 Web 全栈项目闭环：需求、设计、实现、测试、部署、复盘。
- 熟悉 Git 分支协作、代码审查、CI、日志和性能分析。
- 独立完成至少一个可公开访问、可长期维护的项目。
- 准备英语技术阅读和口头答辩，能够清楚解释设计取舍。

## 中期目标（1 至 3 年）

- 结合学院方向选择云原生、数据系统、网络智能或人机交互作为主线。
- 参与实验室或企业实习，经历真实用户、真实数据和真实约束。
- 掌握数据库事务与索引、分布式系统基础、接口安全和可观测性。
- 将 TypeScript、测试工程化和系统设计纳入常规工作流。
- 参与竞赛、开源或科研项目，完成可量化的成果输出。

## 长期目标（3 至 5 年）

- 成为能独立负责复杂模块的工程师，能够从需求中发现技术风险。
- 形成“设计文档先行、自动化验证、线上数据驱动”的工程习惯。
- 在所选方向持续输出技术文章、开源代码或研究成果。
- 具备跨团队沟通、项目管理和技术决策能力。

## 与本项目的对应关系

| 能力 | 本项目证据 |
| --- | --- |
| 需求分析 | 把原评审问题拆成 P0/P1/P2 并逐项闭环 |
| 后端工程 | 预约规则、事务式 JSON 写入、会话和权限 |
| 前端工程 | 响应式平台、管理台、通知中心和交互状态 |
| 图形与交互 | Three.js 数字孪生、Raycaster、数据映射 |
| 测试 | 单元测试、Lint、生产构建、HTTP 冒烟和浏览器验收 |
| 文档与表达 | 技术设计、Vibe 日志、测试用例和答辩讲稿 |

## 行动计划

1. 每月完成一次项目复盘，记录技术债和已解决的根因。
2. 每周至少阅读一篇系统设计、数据库或 Web 安全资料。
3. 每学期完成一个可演示作品，并保留完整工程与测试记录。
4. 在暑期实习前完成算法、计算机网络、数据库和操作系统系统复习。
5. 按实际目标准备英语、竞赛、证书或科研申请，不把证书当作项目替代品。
